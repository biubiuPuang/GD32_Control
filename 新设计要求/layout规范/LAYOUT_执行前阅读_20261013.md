# FV1.0 电动葫芦控制板 LAYOUT 执行说明

设计来源：2026-10-13冻结的原理图和网表；不得自行重命名、合并、短接网表中的功能网络。

## 先进行分区，再开始自动布线

- HV_MAINS: L1、L2、L3、F1原边、C5跨相。
- HV_MOTOR: L11、L21、L31、L21C/O、L31C/O、LL2、LL3和CN3电机输出。
- HV_BRAKE: B1、B2、F2和D5～D8整流节点。注意它们是高压相关网络，不是24V信号。
- CTL_RAW: T1_RAW、T2_RAW、CTRL_SAFE、RF_UPOUT、RF_DNOUT、W_*_RAW及限位反馈。
- LV_PWR/RF: 9V、24V、+5V、VCC、GND、COM_24V；AGND、RFSIG、RFXI、RFXO、SPI、RF1、X1。

## 公司内部占位规则（不能作为CE通过判据）

1. HV不同相/开关功率铜线间：优先6mm或更大，宽裕时8mm；器件焊盘脚距不能据此跳过绝缘复核。
2. HV对控制/MCU/RF：优先10mm跨层投影区和禁铜；无高压从MCU/RF区下方穿过。
3. HV铜到板边：暂按6mm占位；接近安装金属/外壳，按风险重算。
4. 低压3.3V/5V普通信号：0.20mm可作为制造DRC起点，与高压规则分开。
5. 実际电气间隙/爬电距离必须根据 IEC 60664-1 的污染等级、材料CTI、海拔、绝缘等级、过电压类别等核算。

## 固定网络关系

- R54=0Ω：COM_24V↔GND；R26=0Ω：AGND↔GND。不得私自加其他地铜桥。
- T1_RAW→RLY3→CTRL_SAFE→CN1-8 / RLY1-3 / RLY2-3。
- RLY1/2为APY225G3EH，输出CTRL_SAFE→RF_UPOUT/DNOUT→K1；附近铺铜不得跨高压绝缘边界。
- 9VAC/44mA与23VAC/0.2A两组绕组分别整流滤波，不可将大电流回流引到射频区。
- RF1→匹配网络→CMT2219B 依层叠计算50Ω馈线；时钟26MHz要短、近、连续地参考。
