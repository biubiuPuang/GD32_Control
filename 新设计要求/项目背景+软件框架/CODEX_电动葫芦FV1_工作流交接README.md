## 不得擅自改变

1. MCU：GD32E230C8T6；无线接收：CMT2219B；PhotoMOS：APY225G3EH ×2。
2. PB11/MCUESTOP：高=禁止。PB12/MCUIO1：无线升请求；PB13/MCUIO2：无线降请求，均高有效。
3. PA8 / PA9 / PA10分别驱动KA1下降、KA2上升、KA3快速相关光耦，按当前网表为低有效（上板验证）。
4. PB3/PB4是LIFT1/LOWER1反馈采样，**不是有线UP/DN原始按键**。PB5为有线FAST检测。
5. **W_UP_RAW、W_DN_RAW及WIRED_IDLE当前没有接入MCU GPIO。** 软件不得凭空增加该输入，也不能声称无线FAST已经可靠实现有线优先。
6. 未取得遥控器协议资料，禁止自创帧格式、CRC、设备号或超时阈值并将其标为已验证。
7. 公共许可和硬件限位/抱闸由既有电气回路承担；软件指令不代表KM1触点或制动器已动作。

## 软件V1门槛

- 初始化默认禁止：PB11=高，MCUIO1/2=低，PA8/9/10输出设置为不驱动；启动自检前不得许可运行。
- 无线UP和DOWN不可同时请求；无线FAST单独有效不允许运动。**无线FAST在硬件输入缺口关闭前默认禁用。**
- 无线帧必须经协议层→仲裁层→状态机→输出层；射频中断不能直接操作运动GPIO。
- 无线帧超时、异常、MCU重启均需撤销无线命令及许可；具体门槛经协议资料和台架数据确认。
- 急停旋转复位且按键仍按住的旧版兼容行为属于客户已说明事项，但存在重新启动的安全风险，不能据此宣称通过认证。
